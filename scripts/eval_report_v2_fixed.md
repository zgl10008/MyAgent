## 四、简历可引用结论

- 混合检索（BM25 + 向量 + RRF 重排序）相比纯向量检索，Recall@5 变化-15.9%
- 混合检索 MRR = 0.5582，纯向量 MRR = 0.5873，浅排名下略低于纯向量（等权 RRF 被较弱的关键词路稀释，属预期，见召回阶段章节）
- 混合检索平均耗时 37 ms
- 召回阶段（candidate_k=50）混合检索候选集 Recall = 0.872，高于纯向量 0.840（+3.8%），说明双路召回在候选集深度互补
