# RAG 检索召回评估报告（自包含合成数据集）

**评估时间**: 2026-08-07
**知识库**: 6 篇心血管慢病领域合成文档，13 个文档块
**测试查询**: 20 条（高血压/冠心病/糖尿病/心衰/房颤/血脂等）
**嵌入方式**: 字符 n-gram 哈希（256 维，无外部依赖）
**检索算法**: BM25 Okapi / 余弦相似度 / RRF 融合（k=60）
**评估指标**: Recall@K / Precision@K / NDCG@K / MRR

> 运行方式：`python scripts/eval_rag_standalone.py`

## 二、混合检索 vs 纯向量检索（提升幅度）

| 指标 | 提升 |
|------|------|
| Recall@1 | +44.21% |
| Recall@3 | +12.08% |
| Recall@5 | +9.71% |
| Recall@10 | +0.85% |
| NDCG@5 | +20.12% |
| MRR | +21.86% |

## 三、结论

在合成心血管医学语料上，混合检索（BM25 + 向量 + RRF）相比纯向量检索
**Recall@5 从 0.7292 提升至 0.8000（+9.71%）**，MRR 从 0.7146 提升至 0.8708（+21.86%），
单次检索平均耗时仅 0.24ms。

注：本实验为无外部依赖的算法正确性验证；关键词检索在此合成语料上表现突出，
是因为查询中包含大量与文档完全一致的术语。
