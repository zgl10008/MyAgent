## 五、简历可引用结论

- 混合检索（BM25 + 向量 + RRF 重排序）相比纯向量检索，Recall@5 变化-3.9%
- 混合检索 MRR = 0.6222，纯向量 MRR = 0.6272，浅排名下略低于纯向量（等权 RRF 被较弱的关键词路稀释，属预期，见召回阶段章节）
- 混合检索平均耗时 48 ms
- 召回阶段（candidate_k=50）混合检索候选集 Recall = 0.836，高于纯向量 0.777（+7.6%），说明双路召回在候选集深度互补
