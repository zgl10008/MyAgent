# RAG 检索召回评估报告（真实医学指南）

**评估时间**: 2026-08-07
**数据来源**: 中华医学会内分泌学分会《糖尿病合并高血压患者管理指南》(2025)
**知识库**: 78 个原始 chunk，噪声过滤后 32 个有效 chunk
**测试查询**: 20 条（覆盖流行病学/危险因素/诊断标准/药物治疗/BPROAD 研究）
**嵌入方式**: 字符 n-gram 哈希（256 维）
**检索算法**: BM25 Okapi / 余弦相似度 / RRF 融合（k=60）

> 运行方式：`python scripts/eval_real_doc.py`

## 二、混合检索 vs 纯向量检索（提升幅度）

| 指标 | 提升 |
|------|------|
| Recall@1 | +156.59% |
| Recall@3 | +84.90% |
| Recall@5 | +38.92% |
| Recall@10 | +9.96% |
| NDCG@5 | +53.31% |
| MRR | +34.49% |

## 三、结论

在真实中文医学指南语料上，混合检索相比纯向量检索
**Recall@5 从 0.4297 提升至 0.5969（+38.92%）**，MRR 从 0.3919 提升至 0.5271（+34.49%），
验证了双路融合策略在中文医学文献检索中的有效性。

注：本实验使用 n-gram 哈希嵌入（弱于语义嵌入），且小语料下关键词检索表现突出；
全量知识库 + 真实语义嵌入的结论见 [eval_report_full_kb.md](./eval_report_full_kb.md)。
