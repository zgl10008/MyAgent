# 心血管慢病管理 AI Agent —— 演示对话脚本（截图用）

> 用于招聘网站作品展示。以下 5 个场景均已在本机实测通过。
> 前端默认「🤖 自动」模式，后端 `agent_mode: auto` 会自动路由到对应执行范式。

---

## 场景一：RAG 知识问答（带引用）

**输入话术：**

```
高血压的诊断标准是什么
```

**预期展示亮点：**
- 右上角模式徽标自动切到「📚 RAG」
- 回答末尾带 `[1]` 引用，右侧「文档知识库」面板展示检索到的原文片段
- 知识库显示「774 个文本块」

**实测返回（节选）：**

> 高血压的诊断标准为：在未使用降压药物的情况下，非同日 3 次测量诊室血压，
> 收缩压（SBP）≥140mmHg 和（或）舒张压（DBP）≥90mmHg …… [1]

**截图要点：** 主回答区 + 右侧引用面板同框。

## 场景二：ReAct 多步推理 + 工具调用（计算器）

**输入话术：**

```
帮我算一下 (123+456)*789 等于多少
```

**预期展示亮点：**
- 模式徽标「🤖 Agent」，意图徽标「🧮 数值计算」
- 右侧「工具调用日志」显示调用了 `calculator` 工具
- 左侧「Agent 分析过程」展示 Thought→Action→Observation 步骤
- 反思评分 `100`，无幻觉

**实测返回：**

> 计算结果如下：**(123 + 456) × 789 = 456831**
> 计算过程：先算括号内 123 + 456 = 579，再乘以 789，得到 456831。

**截图要点：** 右侧工具调用日志 + 步骤面板同框，体现「多步推理 + 工具调用」。

## 场景三：医疗安全拦截

**输入话术：**

```
我现在胸痛、呼吸困难，感觉快不行了
```

**预期展示亮点：**
- 模式徽标「🚨 医疗安全拦截」（红色）
- **不进入工具调用链**，直接返回急诊引导
- 体现医疗场景的安全兜底设计

**实测返回：**

> 你描述的症状可能提示需要紧急医疗评估（例如急性心脑血管事件）。
> 请立即拨打 120 或前往最近的急诊，不要自行驾车……

**截图要点：** 红色拦截提示卡片 + 引导话术，突出「安全边界」。

## 场景四：多轮记忆

**第 1 轮输入：**

```
我叫张伟，今年 55 岁，有高血压病史 5 年
```

**第 2 轮输入：**

```
我刚才说我的病史是几年？我叫什么？
```

**预期展示亮点：**
- 第 2 轮能准确回忆「张伟」「5 年病史」，体现会话记忆（Redis 短期 + Milvus 长期 + PG 持久三层）

**实测返回（第 2 轮节选）：**

> 根据您刚才提供的信息，我可以确认：1. 您的姓名：张伟 2. 病史年限：5 年

**截图要点：** 两轮对话同框，第 2 轮回答点出记忆内容。

## 场景五（进阶）：Plan-and-Execute 规划执行

**输入话术：**

```
高血压患者的饮食管理有哪些要点？请结合最新指南分步说明
```

**预期展示亮点：**
- 模式徽标显示「plan_execute」，右侧步骤面板展示「规划 → 子任务执行 → 汇总」
- 体现「先规划、再逐子任务 ReAct 执行」的两层架构
- 答案以「第一步 / 第二步 …」结构化输出

**实测返回（节选）：**

> 高血压患者的饮食管理可归纳为「先减害、再增利、后强化」的五步执行方案：
> 第一步：限制钠盐摄入（每日 <5 克）……

**说明：**
- 本场景耗时较长（约 75s，因为要串行跑「意图识别 → 规划 → 4 个子任务 → 汇总 → 反思」多次 LLM 调用）。
- 当前实时搜索 `web_search` 依赖百度，被反爬验证码墙挡住，PE 子任务会自动排除它；本地 `rag_search` 工具可用。

**截图要点：** 右侧「Agent 分析过程」的 plan / execute_subtask / subtask_done 步骤同框。
