# 反思评估机制 — 完整方案设计

## 一、现状分析

### 当前流程

```
Agent 执行 → 生成 answer
  ↓
_reflection (如果 enable_reflection=True)
  ↓ 输入: user_query + answer + trace_summary
  ↓ LLM 返回: { quality_score, is_complete, likely_hallucination, ... }
  ↓
只取 quality_score → 传给前端展示（绿/黄/红）
  ↓
结束。不重试、不修正、不警告用户。
```

### 当前缺陷

| 问题 | 代码位置 | 影响 |
|------|------|------|
| `should_retry_or_warn()` 从未调用 | [reflection.py:146](../../app/core/agent/reflection.py#L146) | 反思结果不产生任何动作 |
| `evidence_snippets` 从未传入 | [orchestrator.py:380](../../app/core/agent/orchestrator.py#L380) | 幻觉检测无依据，全凭 LLM 猜测 |
| `likely_hallucination` 不传给前端 | [agent_service.py:568-572](../../app/core/agent_service.py#L568-L572) | 前端不知道有疑似幻觉 |
| `completeness_notes` 不传给前端 | 同上 | 用户不知道回答是否完整 |
| 低于阈值不触发重试 | [orchestrator.py:275](../../app/core/agent/orchestrator.py#L275) | 低质量回答直接返回给用户 |
| 反思失败直接跳过 | [orchestrator.py:280-282](../../app/core/agent/orchestrator.py#L280-L282) | 用户无感知 |

## 二、设计方案

### 整体流程

```
Agent 执行 → 生成 answer
  ↓
┌─ 反思评估（带 evidence）─────────────────────────────────────┐
│  输入: user_query + answer + evidence_snippets + trace_summary │
│  输出: ReflectionReport                                       │
└──────────────────────────────────────────────────────────────┘
  ↓
  ├─ score ≥ 80 → 直接返回（绿色）
  │
  ├─ score 60-79 → 自我修正（1 次 LLM 调用修复问题）
  │   ↓
  │   └─ 修正后再反思 → 返回最佳版本
  │
  ├─ score 40-59 → 完整重试（重新执行 Agent，携带反思反馈）
  │   ↓（最多 2 次）
  │   └─ 重试后再反思 → 取最高分版本返回
  │
  └─ score < 40 → 完整重试 + 用户可见警告
      ↓（最多 2 次）
      └─ 仍不合格 → 返回最佳版本 + "可能不准确"警告
```

### 三级响应策略

| 分数 | 动作 | LLM 调用增量 | 说明 |
|------|------|------|------|
| **≥ 80** | 直接返回 | 0 | 质量过关 |
| **60-79** | 自我修正 + 再反思 | +2 次 | 轻量修复幻觉/完整性 |
| **< 60** | 完整重试（含反思反馈） | +1 次 Agent 运行 + 1 次反思 | 重新推理，最多 2 次 |

成本上限：一次对话最多额外 4 次 LLM 调用（1 次自我修正 + 2 次反思 + 最多 2 次 Agent 重试中的反思已包含）。

## 三、核心模块设计

### 3.1 Evidence 收集器（新增）

**位置**：`app/core/agent/evidence_collector.py`

```python
@dataclass
class EvidenceSnippet:
    source: str       # "rag_search" | "web_search" | "calculator"
    query: str        # 检索时用的 query
    content: str      # 返回的内容
    timestamp: float

class EvidenceCollector:
    """从 Agent 执行步骤中提取外部证据片段。"""

    def collect(self, steps: list[dict]) -> list[str]:
        """提取所有工具调用结果作为反思证据。"""
        snippets: list[str] = []
        for step in steps:
            action = step.get("action") or step.get("parsed", {}).get("action")
            if action in ("rag_search", "web_search"):
                obs = step.get("observation", "")
                if obs:
                    snippets.append(f"[{action}] {obs}")
        return snippets
```

**关键**：目前 `_run_reflection()` 只传了 `trace_summary`（阶段名列表），不传实际检索结果。Evidence Collector 从 steps 中提取 `rag_search` 和 `web_search` 的 observation，让反思 LLM 能对照证据判断幻觉。

### 3.2 自我修正器（新增）

**位置**：`app/core/agent/reflection.py`

```python
SELF_CORRECTION_PROMPT = """你是答案修正专家。请根据审查意见修正助手回答。

## 审查意见
{reflection_feedback}

## 原始回答
{original_answer}

## 外部证据（用于修正幻觉）
{evidence}

请直接输出修正后的完整回答，不要输出 JSON。修正规则：
- 移除审查指出的虚构事实
- 补充遗漏的关键要点
- 保留正确的部分不改变
- 修正后回答不得虚构新的事实
"""

class SelfCorrector:
    """对低分回答进行单次 LLM 修正，比完整重试便宜。"""

    def __init__(self, llm: ReflectionLLM):
        self._llm = llm

    async def correct(
        self,
        original_answer: str,
        reflection: ReflectionReport,
        evidence: list[str],
    ) -> str:
        """返回修正后的回答。"""
        feedback_parts = []
        if reflection.hallucination_reasons:
            feedback_parts.append("疑似幻觉：" + "；".join(reflection.hallucination_reasons))
        if reflection.suggestions:
            feedback_parts.append("改进建议：" + "；".join(reflection.suggestions))
        if not reflection.is_complete:
            feedback_parts.append("完整性不足：" + reflection.completeness_notes)

        ev_block = "\n".join(f"- {e}" for e in evidence) or "（无外部证据）"

        prompt = SELF_CORRECTION_PROMPT.format(
            reflection_feedback="\n".join(feedback_parts),
            original_answer=original_answer,
            evidence=ev_block,
        )
        raw = await self._llm.acomplete(
            [{"role": "user", "content": prompt}],
            temperature=0.2,
        )
        return raw if isinstance(raw, str) else str(raw)
```

### 3.3 重试管理器（新增）

**位置**：`app/core/agent/reflection.py`

```python
@dataclass
class RetryContext:
    """携带前一轮反思反馈的重试上下文。"""
    hallucination_reasons: list[str]
    missing_points: str
    suggestions: list[str]
    previous_score: int

    def to_hint(self) -> str:
        """生成注入 Agent 的重试提示。"""
        parts = []
        if self.hallucination_reasons:
            parts.append("上一轮疑似虚构以下内容，请避免：" + "；".join(self.hallucination_reasons))
        if self.missing_points:
            parts.append("上一轮遗漏了：" + self.missing_points)
        if self.suggestions:
            parts.append("改进方向：" + "；".join(self.suggestions))
        return "\n".join(parts)


class ReflectionLoop:
    """反思驱动的质量控制循环。"""

    MAX_RETRIES = 2
    CORRECTION_SCORE_THRESHOLD = 60   # < 此分触发自我修正
    RETRY_SCORE_THRESHOLD = 40        # < 此分触发完整重试

    def __init__(
        self,
        reflection_agent: ReflectionAgent,
        self_corrector: SelfCorrector,
        evidence_collector: EvidenceCollector,
    ):
        self._reflect = reflection_agent
        self._correct = self_corrector
        self._evidence = evidence_collector

    async def evaluate_and_improve(
        self,
        user_query: str,
        answer: str,
        steps: list[dict],
    ) -> dict:
        """
        反思 → 决策 → 可能的修正/重试 → 再次反思。

        返回: {
            "final_answer": str,
            "final_score": int,
            "reflection_report": ReflectionReport,
            "corrections_made": int,
            "retries_made": int,
            "action_taken": "none" | "self_correction" | "retry",
            "warnings": list[str],
        }
        """
        evidence = self._evidence.collect(steps)
        retries = 0
        corrections = 0
        warnings: list[str] = []
        best_answer = answer
        best_score = 0
        best_report = None

        report = await self._reflect.reflect(
            user_query, answer,
            evidence_snippets=evidence,
            trace_summary=str([s.get("phase") for s in steps[-20:]]),
        )
        best_score = report.quality_score
        best_report = report

        # 质量合格，直接返回
        if best_score >= 80:
            return self._result(best_answer, best_score, best_report, corrections, retries, "none", warnings)

        # 自我修正（60-79）：比完整重试便宜
        if best_score >= self.CORRECTION_SCORE_THRESHOLD:
            corrected = await self._correct.correct(answer, report, evidence)
            corrections += 1
            report2 = await self._reflect.reflect(
                user_query, corrected,
                evidence_snippets=evidence,
            )
            if report2.quality_score > best_score:
                best_answer = corrected
                best_score = report2.quality_score
                best_report = report2
            if report.likely_hallucination:
                warnings.append("回答经自动修正，可能存在不准确内容")
            return self._result(best_answer, best_score, best_report, corrections, retries, "self_correction", warnings)

        # 完整重试（< 60）：需要外部重试，返回重试上下文
        retry_ctx = RetryContext(
            hallucination_reasons=report.hallucination_reasons,
            missing_points=report.completeness_notes,
            suggestions=report.suggestions,
            previous_score=report.quality_score,
        )
        if report.likely_hallucination and report.quality_score < 40:
            warnings.append("⚠️ 回答可能包含不准确信息，已尝试重新生成")
        return {
            **self._result(best_answer, best_score, best_report, corrections, retries, "retry_needed", warnings),
            "retry_context": retry_ctx,
        }

    def _result(self, answer, score, report, corrections, retries, action, warnings):
        return {
            "final_answer": answer,
            "final_score": score,
            "reflection_report": report,
            "corrections_made": corrections,
            "retries_made": retries,
            "action_taken": action,
            "warnings": warnings,
        }
```

### 3.4 编排器集成（修改）

**位置**：`app/core/agent/orchestrator.py:269-290`

当前代码需要改为：

```python
# 原代码（仅做一次反思，只用 score）
reflection_report = await self._run_reflection(user_input, answer, trace_id, steps)

# 改为（带重试和修正循环）
result = await self._reflection_loop.evaluate_and_improve(
    user_query=user_input,
    answer=answer,
    steps=steps,
)

# 如果需要完整重试
retry_count = 0
while result["action_taken"] == "retry_needed" and retry_count < 2:
    retry_count += 1
    retry_ctx = result["retry_context"]
    retry_hint = retry_ctx.to_hint()

    # 重新执行 Agent，注入反思反馈
    retry_result = await self._invoke_react(
        user_input, session_id, intent_ctx, trace_id, steps,
        suffix=f"[反思重试 #{retry_count}]\n{retry_hint}",

    retry_answer = retry_result.final_answer if retry_result else ""

    result = await self._reflection_loop.evaluate_and_improve(
        user_query=user_input,
        answer=retry_answer,
        steps=steps,
    )

answer = result["final_answer"]
reflection_report = result["reflection_report"]
```

## 六、LLM 调用成本分析

| 场景 | 反思 | 自我修正 | Agent 运行 | 总额外 |
|------|------|------|------|------|
| 高质量回答 (≥80) | 1 次 | 0 | 0 | **0** |
| 中等回答 (60-79) | 2 次 | 1 次 | 0 | **+2 次 LLM** |
| 低质量回答 (<60)，重试 1 次通过 | 2 次 | 0 | 1 次 | **+1 次 Agent + 1 次反思** |
| 极差回答，重试 2 次仍低 | 3 次 | 0 | 2 次 | **+2 次 Agent + 2 次反思** |

最坏情况：额外 2 次 Agent 运行 + 3 次反思 = 单次对话 LLM 调用量约增至 3 倍。但只有 <40 分的极端情况才会触发。
